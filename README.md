# TrackMe - Budget & Expense Tracker

TrackMe is a modern, intuitive Flutter application designed to help you manage your personal finances with ease. Track your daily expenses, set monthly budgets, and visualize your spending habits.

## 🚀 Features

* **Dashboard:** Real-time overview of your budget, total spent, and remaining balance.
* **Expense Tracking:** Add, edit, and delete daily expenses with categories and dates.
* **Budget Management:** Set and update your monthly budget goals.
* **Visual Analytics:** Interactive pie chart showing spending breakdown by category.
* **Smart Filtering:** Search expenses by name/amount and filter by date range or category.
* **Dark Mode:** Fully supported dark theme that respects system settings.
* **Data Persistence:** All data is saved locally using SQLite, ensuring it survives app restarts.
* **Onboarding:** Smooth introduction flow for first-time users.

## 🛠️ Technologies Used

* **GetX:** State management, dependency injection, and route management.
* **Sqflite:** Local SQLite database for robust data persistence.
* **GetStorage:** Lightweight key-value storage for app settings (themes, onboarding).
* **FL Chart:** Beautiful and animated charts for data visualization.
* **Google Fonts:** Modern typography using the Poppins font family.

## 🏁 Getting Started

1. **Clone the repository:**

    ```bash
    git clone https://github.com/mussie-alemayehu/trackme.git
    ```

2. **Install dependencies:**

    ```bash
    flutter pub get
    ```

3. **Run the app:**

    ```bash
    flutter run
    ```
